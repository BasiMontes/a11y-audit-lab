# a11y-audit-lab

Laboratorio de auditoría de accesibilidad con axe sobre una página propia con fallos sembrados (proyecto 5a, WCAG 2.2 AA).

- `pagina/index.html`: página de práctica con 10 fallos sembrados (F1 a F10) y una sección de control.
- `docs/fallos-sembrados.md`: lista de fallos y predicción, escrita antes de medir.
